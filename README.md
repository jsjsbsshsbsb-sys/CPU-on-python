# CPU in Python

Минимальный виртуальный CPU на Python.

## Запуск

Из папки проекта выполни:

```bash
python main.py
```

## Команды

- `LOAD R1, 10` — записывает число в регистр.
- `ADD R1, R2` — складывает R1 и R2, результат остаётся в R1.
- `SUB R1, R2` — вычитает R2 из R1, результат остаётся в R1.
- `STORE R1, 0` — сохраняет значение R1 в ячейку памяти с адресом 0.
- `HLT` — останавливает CPU.

Регистры: `R1`, `R2`, `R3`, `R4`.
Память данных содержит до 256 адресуемых ячеек.
